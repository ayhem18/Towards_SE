# Overview

This project is a tool to backup a given directory of file

## Different functionalities: 

### 1. backup:
- a. backup a given directory or file to the chosen location
- b. encrypt the backup
- c. compress the backup

### 2. restore:
- a. restore a given backup to the chosen location
- b. decrypt the backup
- c. decompress the backup 

### 3. list:
- a. list all backups

### 4. delete:
- a. delete a given backup
- b. delete all backups
- c. delete all backups older than a given age
